# Совместимость, мощность БП и подбор сборки

Вся логика — в `packages/domain` и не зависит от БД и фреймворка: один и тот же код считает
совместимость в браузере (в реальном времени) и на сервере (при сохранении сборки, в корзине,
в AI-агентах и MCP).

## API

| Функция                                 | Что делает                                                            |
| --------------------------------------- | --------------------------------------------------------------------- |
| `checkBuild(build, perf?)`              | Полная проверка: `status`, `issues`, `missing`, `power`, `totalUzs`   |
| `checkCandidate(build, product, perf?)` | «Что будет, если выбрать этот товар» — для списков в конфигураторе    |
| `computePower(build)`                   | Нагрузка, рекомендованная мощность БП, нагрузка на выбранный блок в % |
| `solveBuild(catalog, perf, request)`    | Детерминированный подбор сборки под бюджет и назначение               |
| `solveBuildVariants(...)`               | Три варианта: дешевле (−20%), в бюджет, мощнее (+25%)                 |

Статус сборки: `errors` (есть несовместимость) → `incomplete` (не хватает обязательных деталей) →
`warnings` (собрать можно, есть замечания) → `ok`.

Обязательные слоты: корпус, плата, CPU, память, накопитель, БП; кулер — если у CPU нет боксового;
видеокарта — если у CPU нет встроенной графики.

## Правила

Каждая проблема — код (`compat.<код>` в словарях RU/UZ), уровень и параметры для текста.

| Код                                                 | Уровень           | Когда срабатывает                                                              |
| --------------------------------------------------- | ----------------- | ------------------------------------------------------------------------------ |
| `cpu.socketMismatch`                                | ошибка            | сокет CPU ≠ сокет платы                                                        |
| `cpu.familyUnsupported`                             | ошибка            | чипсет не поддерживает поколение CPU                                           |
| `cpu.biosUpdate`                                    | внимание          | поколению нужна прошивка BIOS (B650/A620 + Ryzen 9000)                         |
| `ram.typeMismatchBoard` / `ram.typeMismatchCpu`     | ошибка            | DDR4/DDR5 не поддерживается платой или CPU                                     |
| `ram.slotsExceeded`                                 | ошибка            | модулей больше, чем слотов                                                     |
| `ram.capacityExceeded`                              | ошибка            | объём больше min(максимум платы, максимум CPU)                                 |
| `ram.speedDowngrade`                                | подсказка         | частота памяти выше поддерживаемой платой                                      |
| `ram.singleChannel`                                 | внимание          | один модуль — одноканальный режим                                              |
| `ram.mixedKits`                                     | внимание          | разные комплекты памяти                                                        |
| `ram.fourDimmDdr5`                                  | подсказка         | четыре модуля DDR5                                                             |
| `case.motherboardFormFactor`                        | ошибка            | форм-фактор платы не поддерживается корпусом                                   |
| `gpu.tooLong`                                       | ошибка            | длина GPU > максимума корпуса (минус 55 мм, если СЖО ставится только во фронт) |
| `gpu.tooThick`                                      | ошибка            | толщина GPU в слотах > допустимой                                              |
| `gpu.noDisplayOutput`                               | внимание          | CPU без iGPU и без видеокарты                                                  |
| `cooler.tooTall`                                    | ошибка            | высота башенного кулера > максимума корпуса                                    |
| `cooler.socketUnsupported`                          | ошибка            | кулер не поддерживает сокет                                                    |
| `cooler.insufficient` / `cooler.weak`               | ошибка / внимание | TDP кулера < TDP CPU / < 85% пиковой мощности                                  |
| `cooler.radiatorUnsupported`                        | ошибка            | радиатор СЖО некуда поставить                                                  |
| `cooler.ramClearance`                               | внимание          | память выше зазора под башенным кулером                                        |
| `cooler.boxed`                                      | подсказка         | используется боксовый кулер                                                    |
| `storage.m2SlotsExceeded`                           | ошибка            | M.2-накопителей больше, чем слотов                                             |
| `storage.m2GenDowngrade`                            | подсказка         | PCIe 5.0 накопитель в плате без Gen5-слота                                     |
| `storage.sataPortsExceeded`                         | ошибка            | SATA-устройств больше, чем портов                                              |
| `storage.bays25Exceeded` / `storage.bays35Exceeded` | ошибка            | не хватает отсеков (2,5″ занимают и свободные 3,5″)                            |
| `psu.insufficient` / `psu.belowRecommended`         | ошибка / внимание | мощность < нагрузки / < рекомендованной                                        |
| `psu.gpuConnectorsMissing`                          | ошибка            | не хватает разъёмов питания GPU                                                |
| `psu.gpuAdapterRequired`                            | внимание          | 12V-2x6 только через адаптер из 8-pin                                          |
| `psu.formFactor` / `psu.tooLong`                    | ошибка            | ATX-блок в SFX-корпус / блок длиннее допустимого                               |
| `fans.sizeUnsupported`                              | ошибка            | размер вентилятора не поддерживается корпусом                                  |
| `fans.slotsExceeded`                                | внимание          | вентиляторов (с комплектными и СЖО) больше мест                                |
| `fans.headersExceeded`                              | подсказка         | вентиляторов больше разъёмов на плате — нужен хаб                              |
| `perf.cpuBottleneck`                                | внимание          | игровой индекс CPU < 90% от требуемого для GPU                                 |
| `perf.pcieBandwidth`                                | подсказка         | видеокарта x8/x4 на плате со старшим PCIe ниже, чем у карты                    |
| `perf.vramLimited`                                  | подсказка         | 8 ГБ видеопамяти у производительной карты                                      |
| `perf.lowRam`                                       | внимание          | меньше 16 ГБ памяти                                                            |
| `perf.hddSystemDrive`                               | внимание          | в системе только HDD                                                           |

## Мощность БП

```
Нагрузка = CPU (PPT/PL2) + GPU (TBP) + плата (35–60 Вт по чипсету) + 5 Вт × модуль DDR5 (3 Вт DDR4)
         + NVMe 7 / SATA SSD 4 / HDD 9 Вт + 3 Вт × вентилятор + помпа 6 Вт + 2 Вт × RGB-устройство + 15 Вт периферия
Рекомендация = max(нагрузка × 1,25; рекомендация вендора GPU), вверх до 50 Вт
```

Запас 25% держит блок в зоне высокого КПД; кратковременные скачки потребления видеокарт
выдерживают блоки стандарта ATX 3.x.

## «Бутылочное горлышко»

Требуемый игровой индекс CPU для видеокарты с индексом `g` (1440p, RTX 5070 = 1,00):
`0,3 + 0,3 × g`. Индексы CPU — относительно Ryzen 7 9800X3D = 1,00. Предупреждение — если CPU
ниже 90% от требуемого. На этапе 8 эвристику заменит расчёт по движку FPS на наборе игр.

## Подборщик

Игры и киберспорт: видеокарты перебираются от сильной к слабой; к каждой берётся самый дешёвый
CPU без «горлышка», остальные слоты — самые дешёвые совместимые детали без замечаний (с учётом
предпочтений: платформа, цвет, форм-фактор, Wi-Fi). Результат — первая сборка, уложившаяся в
бюджет. Работа: перебор CPU по многопоточному индексу при видеокарте ~25% бюджета. Офис: CPU
со встроенной графикой, без видеокарты. В подбор попадают только товары в наличии; результат
всегда проходит `checkBuild` без ошибок (проверяется тестами на реальном каталоге).
