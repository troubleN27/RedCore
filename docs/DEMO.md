# Сценарий демонстрации (10–15 минут)

Работает и без внешних ключей: оплата — мок-шлюз с тестовыми картами Stripe, SMS, письма и
Telegram — в `/ru/dev/inbox`, AI — детерминированный режим (с `GEMINI_API_KEY` — модель).

## Подготовка

```bash
pnpm dev                                  # без Neon: встроенная база с демо-данными
# или с Neon: pnpm db:reset -- --yes && pnpm db:seed
```

Вкладки: сайт `/ru`, консоль `/ops-console-dev` (в продакшене — `ADMIN_BASE_PATH`),
ящик `/ru/dev/inbox`. Вход в консоль: `admin@redcore.uz`, пароль `RedCore-Staff-2026`, при
первом входе — 2FA по QR (Google Authenticator).

## Сценарий

1. **Витрина (2 мин).** Главная → «Каталог» → «Видеокарты»: фильтр по памяти и длине (URL
   меняется), сортировка. Карточка товара: 3D-модель (вращение, цвет, RGB), характеристики,
   «Совместимо с этим». Переключить язык на UZ — всё на узбекском, цены в soʻm.
2. **Конфигуратор (4 мин).** «Собрать ПК»: выбрать процессор AM5, затем плату LGA1700 —
   понятная ошибка совместимости на RU/UZ. Собрать совместимую сборку: 3D-сборка в корпусе,
   режимы «Без панели» и «Разнести», снимок PNG. Панель FPS справа. «Проверить сборку с AI» —
   замечания и кнопка «Заменить». «Сохранить и поделиться» → ссылка `/b/…`, PDF.
3. **FPS (1 мин).** `/fps`: 4K Ультра + DLSS Performance + генерация кадров. Вкладка
   «Хочу N FPS»: Cyberpunk 2077, 60 FPS, 1440p Ультра → три сборки → «Открыть в конфигураторе».
4. **AI-ассистент (1 мин).** Кнопка чата: «Игровой ПК до 15 млн сум» → карточки сборок;
   «Как вернуть товар?» → поддержка.
5. **Покупка (2 мин).** «Вся сборка в корзину» → промокод `REDCORE10` → оформление, самовывоз,
   карта → тестовая карта `4242 4242 4242 4242` → статус «Оплачен» (пришёл вебхук).
   «Получать статусы в Telegram» — в ящике видно сообщение бота.
6. **Консоль (3 мин).** Дашборд: выручка и воронка конфигуратора. Заказ → «Собирается» (в ящике —
   Telegram покупателю) → возврат → «Возвращён». «Склад», «Игры», «AI» (логи, черновики
   описаний), «MCP» (ключ → Cursor/Claude Desktop, журнал вызовов).
7. **MCP (по желанию).** `pnpm mcp:inspect` — Inspector со всеми инструментами магазина.

## Сброс

Встроенная база сбрасывается перезапуском `pnpm dev`. С Neon:
`pnpm db:reset -- --yes && pnpm db:seed` — только для ветки `dev`.
